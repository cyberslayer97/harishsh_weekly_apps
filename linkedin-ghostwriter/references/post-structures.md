# Post Structures

Pick one. Match the structure to the source material, not the other way around.

## 1. Lesson learned (first-person)
**Use when:** the user has a mistake, failure, or surprise to share.
```
[Hook: the surprising result or the mistake, one line]

[What I was trying to do, 1-2 lines]

[What went wrong or what I assumed]

[What actually worked, with the specific change]

[Takeaway: one sentence the reader can apply]
```

## 2. Founder or company story (third-person)
**Use when:** the source is news, a funding story, a launch, or an underdog journey.
```
[Hook: the unexpected fact about the company or founder]

[Context: who they are and what they faced, 2 lines]

[The decision or move that mattered]

[The result, using only verified numbers]

[What builders can take from it]
```

## 3. Contrarian take (first-person)
**Use when:** the user disagrees with common advice and can back it up.
```
[Hook: the common belief, then the pushback]

[Why people believe it]

[Where it breaks, with an example]

[What I do instead]

[The condition under which the common advice is still right]
```

## 4. How I built it (first-person, automation and tech)
**Use when:** the source is a workflow, tool setup, or project.
```
[Hook: the outcome in numbers or time saved]

[The problem before]

[The setup in 3 to 5 short steps]

[What broke or what I'd change]

[Who this is useful for]
```

## 5. News reaction (either)
**Use when:** the source is an article or announcement.
```
[Hook: what happened, in plain words]

[Why it matters for builders, not a summary of the article]

[One implication most coverage misses]

[What I'd watch next]
```

## Choosing quickly
| Source material | Structure |
|---|---|
| "I tried X and it failed" | 1 |
| Article about a company or founder | 2 |
| "Everyone says X but..." | 3 |
| A workflow, automation, or project | 4 |
| A news item or release | 5 |
